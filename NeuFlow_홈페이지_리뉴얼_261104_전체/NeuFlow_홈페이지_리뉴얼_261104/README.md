# NeuFlow 홈페이지 리뉴얼 시안

2026.11.04 사용자 제공 문안 PDF 5쪽을 기준으로 새로 제작한 제품 페이지입니다.

## 구성

제품과 기술 → SIG 원리 및 분석 흐름 → 보고서 핵심 기능 → 의료진·병원 / 환자·피검진자 활용 혜택 → Q&A → 도입·연구 문의.

- `dist/index.html`: 문안 및 화면 구조
- `dist/styles.css`: PC·태블릿·모바일 반응형 디자인
- `dist/app.js`: 보고서 기능 선택, 이미지 확대, 모바일 메뉴
- `dist/assets/`: 로고·Paperlogy 웹폰트·첨부 시각화·SVG 개념도
- `미리보기_PC_전체.jpg`: 최신 NeuFlow 공식 로고를 반영한 PC 전체 화면
- `미리보기_PC_메인.jpg`, `미리보기_모바일_메인.jpg`: PC·모바일 첫 화면
- `문안_반영내역.md`: 첨부 문안 반영 및 표현 정리 내역
- `검수결과.json`, `제작정보.json`: 검수와 자산 정보

설치나 빌드 없이 `dist/index.html`을 브라우저에서 열 수 있습니다. 모든 폰트와 이미지를 포함합니다. 배포 시에는 `dist/` 전체를 업로드합니다. 문안은 HTML 텍스트로 편집할 수 있고, 통이미지로 고정하지 않았습니다.

신규 위험신호 해석은 적용 준비 단계이며 보고서 화면은 구성 예시입니다. 실제 제품 화면·진단 수치·위험 등급을 만든 시안이 아닙니다. 별도의 외부 신규 제품명은 사용하지 않았습니다.

기존 홈페이지와 이전 시안은 변경하지 않았습니다. 검토용 사이트는 소유자 전용 비공개로 별도 구성했습니다.

폰트 라이선스는 `dist/assets/PAPERLOGY-LICENSE.txt`에 포함되어 있습니다.

## 다운로드 패키지

상단 NeuFlow 공식 로고가 반영된 최신 소스입니다. 압축을 푼 다음 `dist/index.html`을 열어 확인하세요. 디자인 수정은 `dist/styles.css`, 문구 수정은 `dist/index.html`, 화면 동작 수정은 `dist/app.js`에서 할 수 있습니다.

외부 디자이너에게 전달하기 편하도록 저장소·인증·호스팅 연결 파일은 제외했습니다. 이미지, 로고, 폰트와 폰트 라이선스를 포함합니다.
